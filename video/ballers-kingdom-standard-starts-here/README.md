# The Standard Starts Here

Source-only 45-second photoreal production package for The Ballers Kingdom. It contains no rendered media, frames, provider credentials, or upload receipts.

Start with `locked_scene_contract.json`, then review `script.md`, `character_bible.md`, `continuity_reference_policy.md`, `shotlist.json`, `video_prompts.md`, `audio_plan.md`, `edit_plan.md`, `render_plan.md`, and `quality_report.md`.

The permitted workflow is local review animatic, explicit approval, one text-free paid clip per scene, frame audit, local QA, then an explicitly authorized unlisted review upload. This package stops before all of those actions.
