# Render Plan and Gates

1. Create a no-cost local animatic from approved stills or placeholders and the locked timing/copy.
2. Obtain explicit user approval of that animatic before any paid scene request.
3. After approval, request one text-free 16:9 photoreal scene per locked prompt; do not request alternate takes unless the user authorizes them.
4. Inspect representative frames from each clip for coach continuity, athlete age, anatomy, ball geometry, active background, and absent readable language.
5. Assemble with post-composited verified graphics, original/approved audio, and the edit plan.
6. Validate H.264/AAC, 1280×720, 24fps, 45±1 seconds, audio stream, readable post graphics, final-ten-second audible bed, and local seek behavior.
7. Stop for explicit authorization before any unlisted-review upload. Public release is outside this package.

Keep rendered clips, extracted frames, provider receipts, and credentials local-only and uncommitted.
