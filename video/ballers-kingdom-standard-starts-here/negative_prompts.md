# Rejection Criteria

Reject: readable language, logos, branded marks, jersey lettering, signs, scoreboards, UI, watermarks, badges, false claims, voice cloning, wrong-age athlete, adult athlete, child athlete, identity drift, wardrobe drift, duplicate limbs, extra fingers, malformed hands, malformed ball, floating feet, dead eyes, frozen background, static presenter, slideshow, unrelated setting, staged empty interaction, night lighting, or a non-photoreal result.
